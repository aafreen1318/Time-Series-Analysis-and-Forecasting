# 📈 Time Series Analysis and Forecasting

## 📌 Project Overview

This project demonstrates an end-to-end **Time Series Analysis and Forecasting** workflow using three different datasets: Vimana aircraft demand, WSB sales quantity, and Store demand.

The analysis covers time series exploration, smoothing techniques, seasonal decomposition, stationarity analysis, statistical time series models, forecasting, model evaluation, and residual analysis.

The project focuses on understanding how different time series characteristics influence the selection and performance of forecasting techniques.

---

## 🎯 Project Objectives

- Analyze time-dependent demand and sales data
- Visualize time series patterns and fluctuations
- Apply Moving Average forecasting
- Apply Exponential Smoothing
- Perform Seasonal Decomposition
- Evaluate stationarity using the Augmented Dickey-Fuller test
- Apply first-order differencing
- Build AR, MA, and ARMA models
- Build an ARIMA forecasting model
- Evaluate forecasting performance using MAPE and RMSE
- Compare forecasting approaches
- Analyze ARIMA residuals
- Extract practical insights from time series analysis

---

## 📊 Datasets

The project uses three time series datasets to demonstrate different forecasting and time series analysis techniques.

### ✈️ Vimana Aircraft Demand

Contains sequential observations of aircraft demand over time.

**Main variable:** `demand`

### 🛍️ WSB Sales

Contains monthly sales quantity and promotional information.

**Main variable:** `Sale Quantity`

### 🏪 Store Demand

Contains daily Store demand observations with calendar dates.

**Main variable:** `demand`
